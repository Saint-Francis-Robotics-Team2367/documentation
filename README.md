## Contributing

Spotted something wrong, outdated, or confusing? Fix it! Edit the Markdown file (the pencil icon on
GitHub works) and open a pull request. If you just learned a term the hard way, add it to the
glossary for the next person.

Conventions:
- Write for someone in their first month on the team. Define jargon or link to the glossary.
- When something changed for 2027, mark it with **2027:** so readers know old tutorials differ.
- Link to the robot code's own docs instead of copying them, so there's only one place to update.
