# Resources

Places to keep learning, sorted by topic. For a guided path, start with
[Getting Started](getting-started.md). This page is for going deeper.

Most of these were written before 2027, so check names against our
[2027 migration notes](https://github.com/Saint-Francis-Robotics-Team2367/2026dev/blob/main/docs/2027-migration.md).

## Core references

- [WPILib documentation](https://docs.wpilib.org/), the main FRC programming reference
- [RobotPy documentation](https://robotpy.readthedocs.io/), for Python setup and the API reference
- [WPILib FRC Glossary](https://docs.wpilib.org/en/stable/docs/software/frc-glossary.html), the
  official glossary (ours is [here](../glossary.md))
- Our robot code docs: [architecture](https://github.com/Saint-Francis-Robotics-Team2367/2026dev/blob/main/docs/architecture.md),
  [simulation](https://github.com/Saint-Francis-Robotics-Team2367/2026dev/blob/main/docs/simulation.md),
  [development](https://github.com/Saint-Francis-Robotics-Team2367/2026dev/blob/main/docs/development.md),
  [2027 migration](https://github.com/Saint-Francis-Robotics-Team2367/2026dev/blob/main/docs/2027-migration.md)

## Python

- [The official Python tutorial](https://docs.python.org/3/tutorial/)
- [Real Python](https://realpython.com/), with clear articles on specific topics (classes, type hints,
  and more)

## Git and GitHub

- [GitHub Skills](https://skills.github.com/), interactive courses
- [Pro Git book](https://git-scm.com/book/en/v2), free online
- Our [Git workflow](git-workflow.md)

## Command-based programming

- [WPILib: Command-Based Programming](https://docs.wpilib.org/en/stable/docs/software/commandbased/index.html)
- [WPILib: Command Compositions](https://docs.wpilib.org/en/stable/docs/software/commandbased/command-compositions.html)
- [RobotPy examples](https://github.com/robotpy/examples), small complete Python robot projects
  (check which season each one targets)

## Drivetrain, kinematics, and odometry

- [WPILib: Kinematics and Odometry](https://docs.wpilib.org/en/stable/docs/software/kinematics-and-odometry/index.html)
- [WPILib: Coordinate System](https://docs.wpilib.org/en/stable/docs/software/basic-programming/coordinate-system.html)
- [WPILib: Pose Estimators](https://docs.wpilib.org/en/stable/docs/software/advanced-controls/state-space/state-space-pose-estimators.html),
  for combining odometry with vision
- [Team 4253 swerve docs](https://raidzero-swerve-docs.readthedocs.io), a full guide to bringing up
  a swerve drive

## Controls

- [WPILib: Advanced Controls introduction](https://docs.wpilib.org/en/stable/docs/software/advanced-controls/introduction/index.html),
  including interactive PID and feedforward tuning
- [WPILib: System Identification (SysId)](https://docs.wpilib.org/en/stable/docs/software/advanced-controls/system-identification/index.html)
- [Controls Engineering in FRC](https://file.tavsys.net/control/controls-engineering-in-frc.pdf)
  by Tyler Veness. This is the deep end, so read it after the WPILib pages.

## Simulation, logging, and dashboards

- [WPILib: Robot Simulation](https://docs.wpilib.org/en/stable/docs/software/wpilib-tools/robot-simulation/introduction.html)
- [AdvantageScope docs](https://docs.advantagescope.org/)
- [Elastic dashboard docs](https://frc-elastic.gitbook.io/docs)

## Hardware vendors

- [CTRE Phoenix 6 docs](https://v6.docs.ctr-electronics.com/) for TalonFX, Kraken, CANcoder,
  Pigeon, CANivore, and Tuner X
- [REV Robotics docs](https://docs.revrobotics.com/) for SPARK MAX/Flex and NEO

## Autonomous and vision

- [PathPlanner](https://pathplanner.dev/)
- [Choreo](https://choreo.autos/)
- [PhotonVision](https://docs.photonvision.org/)
- [Limelight docs](https://docs.limelightvision.io/)
- [WPILib: AprilTag introduction](https://docs.wpilib.org/en/stable/docs/software/vision-processing/apriltag/apriltag-intro.html)

## Community

- [Chief Delphi](https://www.chiefdelphi.com/), the FRC forum. Search before asking, since someone
  has probably hit your bug before.
- Open-source robot code from top teams (for example 254, 6328, 971, 1678) shows how experienced
  teams structure things, even when it's in Java.
